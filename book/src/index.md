# provkit, read in order

This book walks through the provkit source one layer at a time, lowest
layer first, so each layer is read after the ones it uses. Every stop
says what the code does, why it has that shape, which Rust it uses, and
what to run to see it work.

Start with [One document, three views](start/three-views.md). Then pick
the track that fits you, [New to Rust](start/new-to-rust.md) or
[New to PROV](start/new-to-prov.md), or go straight to
[Stop 0](stops/0-orientation.md).
